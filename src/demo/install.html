Install Focus Limiter

It isn't on the Chrome Web Store yet, so it installs from source as an unpacked extension. That takes about a minute and needs Node 20 or newer. Chrome keeps unpacked extensions across restarts, so this is a one-time job.

  1. Clone the repository

    git clone https://github.com/gagan86nagpal/focus-limiter.git
cd focus-limiter

  2. Install dependencies and build

    npm install
npm run build

    This writes the loadable extension into dist/. Leave it where it is — Chrome loads it from that folder rather than copying it.

  3. Load it into Chrome

    Open chrome://extensions, turn on Developer mode with the switch in the top right, click Load unpacked, and select the dist/ folder you just built.

  4. Set your first limit

    Click the Focus Limiter icon in the toolbar to open the dashboard, then add a rule — a URL pattern and a number of minutes. That is the whole setup. It is the same dashboard you just used on the demo tab.

Keeping it up to date

Because Chrome reads the folder on disk, updating is git pull && npm run build, then the reload arrow on the extension's card in chrome://extensions. Your rules and history live in Chrome's own storage and survive the rebuild.

What it can see

Focus Limiter asks for no network permission and has no server to talk to. Times and patterns stay in your browser's local storage, activity is kept for 30 days and then rolls off, and the extension is about two thousand lines of TypeScript you can read in an afternoon.
